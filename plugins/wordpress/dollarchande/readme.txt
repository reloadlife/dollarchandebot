نرخ بازار آزاد دلارچنده را در برگه و نوشته نشان می‌دهد.

== Description ==

نرخ را از API دلارچنده می‌خواند. کلید را با /key از ربات بگیر. واحد تومان است.

کد کوتاه:

`[dollarchande symbol="USD"]`

در قالب:

`dollarchande_rate('USD')`

== Installation ==

1. پوشه را در `wp-content/plugins` بگذارید، یا فایل فشرده را از پیشخوان بارگذاری کنید.
2. افزونه را فعال کنید.
3. از تنظیمات، دلارچنده، نماد پیش‌فرض را انتخاب کنید.
4. کد کوتاه را در برگه یا نوشته بگذارید.
