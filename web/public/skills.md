# Skills

> مهارت‌های عامل برای دلارچنده. هر لینک یک SKILL.md مطابق agentskills.io است. DollarChande agent skills. Each link is one skill.

نرخ‌ها بازار آزاد به تومان‌اند و توصیه مالی نیستند. هر کلاینت API کلید ربات را می‌فرستد. بدون کلید پاسخ ۴۰۱ است.

## Skills

- [dollarchande-rates](https://dollarchande.live/skills/dollarchande-rates/SKILL.md): خواندن نرخ ارز، طلا، سکه و تتر به تومان از API
- [dollarchande-plugins](https://dollarchande.live/skills/dollarchande-plugins/SKILL.md): نصب افزونه رایگان وردپرس، ووکامرس یا WHMCS
- [dollarchande-alerts](https://dollarchande.live/skills/dollarchande-alerts/SKILL.md): ساختن و حذف هشدار قیمت در ربات تلگرام
